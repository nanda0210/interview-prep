🧭What this site is

A living interview-preparation library. A single web page links every study document, and an AI agent automatically writes fresh interview Q&A into the material every day — so the content keeps growing without anyone editing it by hand.

📚
Document hubOne page (index.html) that links all PDFs and Markdown study docs, grouped by topic (Python, DevOps, AWS, NVIDIA, handbooks…).
🤖
Daily agentA scheduled program that generates new Q&A with Claude and appends them to the topic files — append-only, never deleting your content.

🤖The daily agent — functionality

A small Python program (in the _agent/ folder) that uses the Claude API to author new interview questions and answers.

🧠
AI modelAnthropic Claude Sonnet 4.6 (claude-sonnet-4-6) via the official anthropic SDK, using prompt caching.
🗂️
Orchestrator_agent/orchestrator.py — the "manager": pulls the repo, finds the topic .md files, runs one sub-agent per file, writes the changelog, commits & pushes.
✍️
Sub-agent_agent/subagent.py — the "writer": for one file, asks Claude for 4 new Q&A (PREP_ITEMS=4) and appends them under a dated heading. Append-only — it never edits or deletes existing content.
🧾
De-duplication_agent/state.json remembers previously-asked questions so the agent never repeats itself.
📈
ChangelogEach run appends a timestamped summary to AGENT-CHANGELOG.md (which files changed, which questions were added).

⏰How the agent is invoked

It runs in the cloud on a schedule — not on anyone's computer. GitHub Actions is the trigger.

The schedule (.github/workflows/daily-prep.yml)

# Runs every day at 15:00 UTC (~8 AM PDT)
schedule:
  - cron: "0 15 * * *"
workflow_dispatch: {}   # also allows manual "Run workflow"

env:
  ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
  PREP_MODEL: claude-sonnet-4-6
  PREP_ITEMS: "4"
run: python3 _agent/orchestrator.py
🔑
API keyStored as a GitHub repo secret (ANTHROPIC_API_KEY) — never committed to the code.
🖐️
Manual runAnytime via the repo's Actions tab → "Run workflow", or the CLI gh workflow run daily-prep.yml.
It previously ran on a Mac via launchd, but macOS blocked background access to the folder — so it was moved to GitHub Actions, which runs reliably regardless of whether your computer is on.

🔄What happens on each daily run

  1. GitHub Actions wakes at 15:00 UTC and checks out the repo (Python 3.12, installs anthropic).
  2. Git pull — get the latest content first.
  3. Discover every topic .md file in the repo.
  4. For each file, run a sub-agent: send the subject + previously-asked questions to Claude Sonnet 4.6, get 4 fresh Q&A.
  5. Append the new Q&A under a dated heading (existing content untouched); update state.json.
  6. Write a timestamped entry to AGENT-CHANGELOG.md.
  7. Commit & push back to the repo (as github-actions[bot]).
  8. GitHub Pages auto-rebuilds → the site now shows the updated documents.
